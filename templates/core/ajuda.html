{% extends "base_user.html" %} {% comment %} Tela de Ajuda. Duas metades, com origens diferentes e propositalmente separadas na tela: 1. "Como funciona" — derivado de `core.ajuda.perguntas_frequentes`, que lê a política vigente. Nenhum número aqui é digitado; se o administrador mudar o horário de funcionamento, esta tela muda junto. É a razão de a metade existir como código e não como texto. 2. "Orientações da administração" — blocos de `core.models.HelpArticle`, escritos por quem sabe. Texto puro, escapado pelo template: um bloco editável nunca vira marcação. Não há seção de contato porque não há contato real cadastrado no sistema. Inventar um telefone na tela de ajuda seria o pior lugar possível para um dado falso. No lugar, o rodapé encaminha para Consultar Normas, que existe. Acessibilidade: o índice é um `nav` com lista de âncoras; cada pergunta é uma `section` com `aria-labelledby` apontando para o próprio título, de modo que um leitor de tela anuncie a pergunta antes da resposta. {% endcomment %} {% block title %}Ajuda - Reserva de Espaços{% endblock %} {% block user_content %}
